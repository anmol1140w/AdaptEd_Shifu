# Assessment question banks

The PCM demo banks cover 14 concepts per subject/class set. Each concept has an easy, medium, and hard short-answer item, with a separate Bloom taxonomy level
and an answer guide. That is 42 items in each bank and 252 total across Physics,
Chemistry, and Mathematics for Classes 11 and 12.

Each item links to its lesson, authored support chunks, original-content
reference, and CBSE syllabus-alignment reference. The original lesson chunks are
the evidence for the item; the CBSE curriculum reference is only for syllabus
alignment. These Ollama-generated items are marked `teacher_approved: false`
and `citation_status: teacher_review_required`; review answer keys and question
quality before using them in a live learner assessment.

The original Algebra fixture banks remain separate for the existing local demo.
