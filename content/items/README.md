# Assessment question banks

The PCM draft banks contain 263 short-answer items across Physics, Chemistry,
and Mathematics for Classes 11 and 12. The original 42-item banks cover 14
concepts per subject/class set; 11 additional drafts fill previously unmapped
concepts in Class 11 Mathematics, Class 12 Mathematics, Class 11 Physics, and
Class 12 Physics. Every authored concept now has at least one mapped question.
Question counts by subject/class are Chemistry 42/42, Mathematics 45/43, and
Physics 46/45 for Classes 11/12 respectively. Questions carry a Bloom taxonomy
level and answer guide.

Each item links to its lesson, authored support chunks, original-content
reference, or CBSE syllabus-alignment reference where present. The CBSE
curriculum reference is for syllabus alignment only. All starter items, including
the 11 new drafts, remain `teacher_approved: false` and
`citation_status: teacher_review_required`; review answer keys and question
quality before using them in a live learner assessment.

The original Algebra fixture banks remain separate for the existing local demo.
