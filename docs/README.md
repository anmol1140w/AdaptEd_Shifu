# AdaptEd documentation

This directory contains the engineering-facing documentation for AdaptEd.

- `product/` describes the MVP scope, user flows and acceptance criteria.
- `architecture/` describes system boundaries, data ownership and technical decisions.
- `research/` contains research and evidence notes used by the implementation team.
- `pitch/` contains presentation and demonstration material.
- `team/` contains the four-person work division and integration rules.

The PS-22 planning documents are grouped here by purpose: product, architecture, research and pitch.
