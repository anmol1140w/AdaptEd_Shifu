# AdaptEd documentation

This directory contains the engineering-facing documentation for AdaptEd.

- `product/` describes the MVP scope, user flows and acceptance criteria.
- `architecture/` describes system boundaries, data ownership and technical decisions.
- `research/` is reserved for research and evidence notes used by the implementation team.
- `pitch/` is reserved for presentation and demonstration material when the existing planning documents are reorganised.

The original PS-22 planning documents remain at the repository root for now so existing references stay stable.
