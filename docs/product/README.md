# Product documentation

This area will contain the product contract for AdaptEd:

- MVP scope and explicit exclusions.
- Learner and teacher user flows.
- Subject-wise summary and concept-wise drill-down behavior.
- Acceptance criteria for the adaptive learning loop.
- Demo assumptions and synthetic-data rules.

Product decisions should be written here before they become implementation assumptions.

The PS-22 problem statement is stored in `Problem_statement.md` in this directory.
